# Social Media, Blog & Channel Posting APIs

This document indexes platforms and networks offering APIs for programmatic post creation, blog publishing, channel announcements, group publishing, and media sharing.

---

## 1. Meta Ecosystem (Facebook & Instagram)
*   **Instagram Graph API (Content Publishing API)**
    *   *Capabilities*: Publish single-image posts, carousels, and Reels to professional accounts (Creator or Business accounts). Supports caption creation, geo-tagging, and media container publishing.
*   **Facebook Graph API (Pages & Groups API)**
    *   *Capabilities*: Publish status updates, photos, links, and video content directly to **Facebook Pages**. Also supports **Facebook Groups API** (for admins of public/private groups to publish posts, provided group members/authors authorize the app).

## 2. Professional & Microblogging Networks
*   **X (formerly Twitter) API v2**
    *   *Capabilities*: Create posts (tweets), attach media (images, GIFs, videos), poll creation, quote tweets, and thread creation. Free and paid tiers available depending on rate limits.
*   **LinkedIn Community Management & Share APIs**
    *   *Capabilities*: Publish text posts, rich articles, image/video posts, and polls to **Personal Profile Feeds** and **LinkedIn Organization Pages**.
*   **Threads API (Meta)**
    *   *Capabilities*: Create text and media posts on Threads (Meta's text-based conversation app) via the Threads API. Supports scheduling, publishing, and retrieving user insights.

## 3. Blogging & Long-Form Publishing Platforms
*   **Medium API & Integration Tokens**
    *   *Capabilities*: Publish stories directly to Medium publications or author profiles. Supports Markdown/HTML body content, tags, canonical URLs, and publication status (draft/public).
*   **WordPress REST API / XML-RPC**
    *   *Capabilities*: Full CRUD (Create, Read, Update, Delete) for blog posts, custom post types, categories, tags, comments, and media uploads across self-hosted WordPress sites and WordPress.com VIP/Cloud.
*   **Substack (RSS & Webhook Syndication)**
    *   *Capabilities*: Provides robust **RSS/Atom feeds** and webhook integrations for automation platforms (Zapier/Make) to trigger posts.
*   **Ghost Admin & Content API**
    *   *Capabilities*: Headless publishing platform offering an extremely clean Admin API to create, schedule, and publish blog posts, pages, tags, and newsletters programmatically.
*   **Dev.to / Forem API**
    *   *Capabilities*: Publish articles, tutorials, and announcements to the Dev.to developer community platform via API keys. Supports markdown frontmatter.
*   **Hashnode API (GraphQL)**
    *   *Capabilities*: Powerful GraphQL mutation API to publish long-form blog posts, manage publications, and sync articles to custom domains on Hashnode.

## 4. Professional Communities & Forums
*   **Reddit API**
    *   *Capabilities*: Submit text posts (self-posts), link posts, or media posts to subreddits or user profiles. Supports moderation, comment posting, and automated syndication bots.
*   **Discord API (Webhooks & Bot API)**
    *   *Capabilities*: Push rich-embed announcements, blog post summaries, and automated alerts directly into **Discord Channels** using Webhooks or Bot REST endpoints.
*   **Slack API (Incoming Webhooks & Chat API)**
    *   *Capabilities*: Broadcast new blog posts, release notes, or alerts into specific **Slack Channels** or direct messages.
*   **Telegram Bot API**
    *   *Capabilities*: Send messages, rich media, and blog post previews automatically to **Telegram Channels** and group chats via Telegram Bot tokens.

## 5. Visual & Creative Platforms
*   **Pinterest API for Business**
    *   *Capabilities*: Create Pins (images, descriptions, destination links) and organize them into boards programmatically.
*   **Tumblr API v2**
    *   *Capabilities*: Publish text posts, photos, quotes, links, and video posts to Tumblr blogs and dashboards.
*   **YouTube Data API v3**
    *   *Capabilities*: Upload video content, update video metadata, manage community posts (for eligible channels), and reply to comments.
